Things and Inventory

Mining, smelting and crafting produce instances of subtypes of Ore, Alloy, or Crafted, respectively. These are all subtypes of Thing. Each concrete subtype of Thing has a count field indicating a quantity of that Thing.

One can make a Thing using a concrete constructor

using IdlePlanetMinerTools

Battery(3)
Battery(3.0)

or using the @t_str macro, which makes the named thing with a count of 1.

t"battery"
Battery(1.0)

Note that for convenience, @t_str uses a dictionary of all concrate Thing subtypes and finds the closest string match.

An Inventory represents a collection of disperate Things.

For convenience, there is a total ordering defined on all concrete subtypes of Thing.

Recipies

A Recipie describes how to smelt an [Ore]((@ref) to an [Alloy](@ref), anAlloyto a [Crafted](@ref) item or to create a [Project`](@ref) from such things.

You can lookup a recipie using an rx string:

using IdlePlanetMinerTools

rx"LaserTorch"

rx"Advanced Crafter"
Recipie(AdvancedCrafter, Inventory(Thing[GoldBar(50.0), Lens(5.0)]), 0)

Arithmetic

Arithmetic operations are defined for Things and Inventorys:

using IdlePlanetMinerTools

need = 7 * delta(rx"gravity chamber")

have = GravityChamber(4) + AdvancedComputer(42) + BasicComputer(64) + Circuit(902)

actions, result = crafting_plan(have - need)
(CraftingAction[CraftingAction(Recipie(GravityChamber, Inventory(Thing[AdvancedComputer(-60.0), NuclearReactor(-1.0)]), 24300), 3)], Inventory(Thing[Circuit(902.0), BasicComputer(64.0), AdvancedComputer(282.0), NuclearReactor(4.0), GravityChamber(0.0)]))

Projects

Once you reasearch a Project the game improves on your capabilities or gives you access to additional functionality. Each Project has a Recipie that describes what you need to be able to reasearch it. Most Projects also have prerequisites which are other projects that you need to have reasearched beforehand.

Once you've researched a project, you should add it to DEFAULT_MODIFIERS so that its benefits will be used throughout this package.

Modifiers

During the course of the game, the player may accumulate status that alters calculations. Among these are Projects, Managers and space ship Rooms. Each of these is a kind of Modifier. DEFAULT_MODIFIERS is a list of modifiers that the player has said they already have. It is used by delta to determine what is needed to complete a Recipie if another list of Modifiers is not passed to it.
